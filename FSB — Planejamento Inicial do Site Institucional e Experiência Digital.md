# FSB — PLANEJAMENTO INICIAL DO SITE INSTITUCIONAL

## 1. Conceito geral

A página inicial não deve funcionar como um simples catálogo de serviços.

Ela deve funcionar como uma **experiência de entrada para o universo FSB**.

A proposta:

**FSB**
  
Uma empresa que transforma momentos em experiências e transforma produtos em desejo.

A experiência inicial será dividida em:

**01. Impacto visual**
→ vídeo cinematográfico de abertura

**02. Escolha do caminho**
→ Events
→ Company

**03. Apresentação da empresa**
→ vídeo institucional
→ visão da FSB

**04. Serviços**
→ acesso aos universos específicos

**05. Encerramento**
→ novamente Events / Company
→ CTA
→ redes sociais / contato

# 3. Conceito do vídeo de abertura

A ideia não é fazer um vídeo institucional tradicional.

É praticamente um:

**visual identity trailer**

O espectador deve sentir que está entrando em um universo.

O vídeo deve começar com um elemento extremamente próximo da câmera.

Por exemplo:

um detalhe de uma câmera profissional.

A câmera faz um movimento rápido para frente.

O zoom atravessa o elemento.

A imagem muda violentamente para outro cenário.

Exemplo:

# 5. Importante: gerar o vídeo em duas etapas

Eu não tentaria obrigatoriamente fazer tudo em um único vídeo.

Uma abordagem melhor é:

### VÍDEO A
Hero principal

4–8 segundos.

Serve para:

- abrir a página;
- impressionar;
- apresentar os universos;
- estabelecer a linguagem visual.

### VÍDEO B
Versão institucional

O mesmo material visual pode ser usado inicialmente.

Depois, quando a FSB possuir um filme institucional real, basta substituir o vídeo.

A estrutura do site não muda.

O Veo 3.1 permite também usar imagens de referência para manter elementos visuais mais consistentes entre gerações.

# 6. O áudio do Hero

A ideia de manter a música tocando depois do vídeo é excelente.

A experiência seria:

VIDEO HERO
↓
música continua
↓
vídeo reduz / fica atrás
↓
interface aparece

Porém, tecnicamente, o navegador pode bloquear reprodução automática de áudio com som.

Por isso a implementação deve prever:

- vídeo inicialmente muted;
- botão discreto de áudio;
- ao primeiro clique/interação do usuário, habilitar a trilha;
- manter o áudio através das transições da página.

Assim você consegue preservar a ideia sem depender de autoplay com som.

# 9. Efeito de hover dos cards

Essa é uma das partes mais importantes da experiência.

O card normalmente apresenta:

- fundo escuro;
- título;
- descrição;
- pequena imagem;
- algum movimento de câmera extremamente lento.

Ao passar o mouse:

O card ganha profundidade.

Aparecem várias imagens atrás dele.

Como se fossem:

### CARD PRINCIPAL

e atrás:

PHOTO 01
PHOTO 02
PHOTO 03
PHOTO 04
PHOTO 05
PHOTO 06

Essas imagens ficam em diferentes níveis de profundidade.

# 10. Interação de movimento

Não utilizar apenas um efeito de parallax convencional.

O mouse deve controlar uma sequência visual.

Exemplo:

movimento do mouse para direita

→ troca imagem

movimento para esquerda

→ troca imagem

movimento para cima

→ troca imagem

movimento para baixo

→ troca imagem

movimento diagonal

→ troca imagem

Cada mudança deve produzir:

- rapid zoom;
- blur;
- motion blur;
- escala;
- deslocamento;
- pequena rotação;
- troca de camada.

A sensação deve ser semelhante a:

**“a câmera está atravessando diferentes trabalhos da FSB.”**

Não precisa ser literalmente aleatório.

O ideal é utilizar uma sequência pseudoaleatória controlada para evitar que a mesma imagem apareça repetidamente.

# 24. Estratégia de idioma

Não criar:

```text
Events page
Company page
```

com textos hardcoded espalhados pelo código.

Estruturar desde o início:

```text
/locales
├── pt-BR.json
└── en-US.json
```

Exemplo:

```json
{
  "home": {
    "choosePath": "Escolha o seu caminho",
    "events": "Eventos",
    "company": "Empresas",
    "experiences": "Experiências",
    "brands": "Marcas",
    "products": "Produtos"
  }
}
```

Depois:

```json
{
  "home": {
    "choosePath": "Choose your path",
    "events": "Events",
    "company": "Company",
    "experiences": "Experiences",
    "brands": "Brands",
    "products": "Products"
  }
}
```

Isso também permite posteriormente colocar:

**PT | EN**

no topo.

# 27. Direção de arte que eu seguiria

A principal decisão visual que eu faria é:

**menos “site de agência” e mais “trailer interativo”.**

O visitante não deve entrar e imediatamente ver:

“Fotografia | Filmagem | DJ | Sites | Sistemas”.

Isso transforma a FSB em uma lista de serviços.

A Home deve primeiro comunicar:

**“Quem é essa empresa e por que ela parece diferente?”**

Só depois:

**“O que exatamente ela faz?”**

Por isso:

**IMPACTO → IDENTIDADE → ESCOLHA → EXPLICAÇÃO → SERVIÇOS**

Essa sequência deixa a marca muito mais forte.
